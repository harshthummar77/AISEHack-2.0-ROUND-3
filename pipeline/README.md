# Pipeline

Processing scripts, numbered in execution order. Two libraries do the heavy lifting:

| File | Contents |
|---|---|
| `sarlib.py` | RPC00B forward model, Capella radiometric calibration, per-range-sample incidence, terrain-referenced inverse geocoding |
| `cropmodel.py` | agronomic knowledge base — crop calendar, district yields, season factor, canopy model. Every non-SAR input is declared here with its source |

Everything else is a stage. The **`.ipynb` at the repo root is the authoritative,
executed pipeline** — these scripts are the same code in runnable form, used during
development and to generate the deliverables.

## Order

| Stage | Scripts | What it does |
|---|---|---|
| Inspect | `01`–`04` | scene metadata, calibration constants, RPC validated against the 225 embedded GCPs |
| Geocode | `10`–`14` | reference-height experiment, terrain referencing (Copernicus GLO-30 + datum solved from GCPs), SLC → 2 m γ⁰, validation vs Capella's own GEO product |
| Phase | `15`–`17` | interferometric baselines, sub-aperture coherence, and the tests that showed it null |
| Zonal | `20`–`22` | bounded co-registration, per-plot statistics, exploratory structure |
| Optical | `30`–`31` | Sentinel-2 NDVI (**validation only**) and the same-day comparison |
| Model | `40`–`41`, `50`–`51` | crop assignment + adjudication, yield forecast + Monte Carlo, crop-mix scenarios |
| Outputs | `60`, `70` | media gallery maps and charts, deliverable tables |

Packaging and QA scripts — the notebook and deck generators, the diagram, and our
own submission checks — are deliberately kept out of this repository. They produce
deliverables but are workflow, not part of the processing chain.

## Running

```bash
python pipeline/13_dem.py        # fetches the DEM, solves the geoid offset
python pipeline/10_geocode.py    # ~6 min, writes pipeline/geo/*.tif
python pipeline/20_zonal.py      # co-registration + per-plot statistics
python pipeline/40_classify.py
python pipeline/50_yield.py
python pipeline/70_deliverables.py
```

Scripts resolve paths relative to the repo root, so run them from anywhere.
`pipeline/geo/`, `pipeline/out/` and `pipeline/s2/` are runtime outputs and are
gitignored — they are regenerated by the code.

Requires the competition `DATA/` folder in the repo root, plus internet access
for the Copernicus DEM (46 MB) and the Sentinel-2 validation.

```
numpy scipy pandas geopandas rasterio shapely pyproj scikit-learn scikit-image
matplotlib openpyxl python-pptx pymupdf
```

**Note:** on Windows with Smart App Control enabled, current `rasterio` wheels are
blocked; `rasterio==1.3.11` works.
